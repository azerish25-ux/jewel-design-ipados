# ADR0033: owned native collection outputs

Status: local native/source verification; Apple source-specific validation pending.

Curve references now include optional ItemIndex, default0 for previous single-curve callers. Each graph output owns immutable channel values and native curve entries keyed by channel/item. Root native curves keep item0; generated array leaves receive positive item addresses. Relaying arrays rewrites curve references and retains their curve/rail/profile/matrix metadata. Missing/null and nested structure are preserved. This is runtime state only, not a CSG field/schema change.

Output owns and disposes every entry; failed RelayOutput construction disposes partial retains. CandidateDataSnapshot is an explicit independent owner for an immutable value tree, with per-leaf retained handles and semantic metadata. Capture resolves raw stored-profile DTOs from immutable document data into native imports, so a snapshot can read them after graph disposal. Capture failure cleans both previously retained and newly imported curves. Snapshot operations require the original live CandidateContext, like existing retained readers. Disposing a snapshot does not invalidate separately retained leaf handles.

Enable source CSArray/CSUnarray1 over the known runtime data slice. Their constructor replay has zero fixed inputs. Array appends data or enumerates all producer outputs for channel-1; saved load quirks still apply. Unarray expands exactly one level, preserves null members, throws on a null input object and appends an always-empty array as the final output. Do not turn that final array into an aggregate or recursively flatten nested members. Dynamic channel counts and invalid-output empty data now use actual cached channels.

A13-A02 separates collection ownership from A03 consuming behavior. Array object transforms/input transform flattening/curve-first-item conversions/aggregate bounds/CSAdd provider arrays remain explicitly unsupported or source-correct scalar conversion failure until adapted. No array is silently replaced with its first curve. Selector forwarding owns retained nested snapshots. Existing scalar Add/external number/default behavior is preserved through fixed output channels.

Exact recovered Array/Unarray Update bodies are compiled with observation-only channels, data and producer lists.18 output comparisons cover six original ready collection chains and nested one-level cases. Independent tests exercise source wildcard/null/trailing-empty semantics, actual3-profile arrays, parameter arrays, item-addressed metadata and geometry, nested retained snapshots across upstream-only rebuild/full replacement/graph disposal, raw stored-profile imports, edits/save/reopen, selector copies, partial capture invalid-reference/resource failure, producer failure/cycles and zero native-entry cleanup. Fourteen other original collections still reject unported producer closures.

The collection source helper models existing scalar producer output counts (3/4/5), stored profile group counts and current native cached output counts. Source runtime wildcard body is tested directly; its saved negative-channel HasLink/reuse behavior is separately covered by exact load replay. Static scene import side effects/material/output flags are not claimed.

Full parent A13 remains in progress. Required A03 operations, broader data/material/segmentation/4x4/producer families, original-PC ordering/geometry/editable PC-iPad-PC, physical-device and full UI/render/export acceptance remain open. No full parity row closes. Resource bounds reject explicitly without truncation; no preview or surrogate geometry is used.
