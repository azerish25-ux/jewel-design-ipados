# A05-P03-A02 actual offline image decoding and ownership

Parent: [SetView collaborators](P08-T01-A05-03f-02b-A05-P03-setview-effects.md); requirement UI-039. This parent is in progress: F01 actual local assets/Apple decoding is verified in its bounded fixtures; full image formats, source conversion, textures/drawing and setter/document integration remain open.

Consume [original bitmap source](../../evidence/audit/rhino5-bitmap-loading-source.json) and [raster source](../../evidence/audit/rhino5-wallpaper-raster-source.json). Retain original requested filename and encoded bytes separately from any decoded object, texture or Windows path. Original table success can precede decode failure. Original codec entry points and hashes are recorded; do not execute the Windows DLLs.

1. Implement immutable, bounded encoded-image assets from explicit local Files imports or bundled/embedded bytes. Preserve original path as inert metadata; resolve through a concrete local import mapping. Never request accounts, use credentials or execute a Windows path/script. Cache keys must not silently conflate original case-insensitive name identity, imported-file identity, gray mode and content. Source cache invalidation helpers remain unresolved; do not invent equivalence.
2. Use a real Apple image decoder with native resource disposal. Validate dimensions and memory budgets before allocating decoded pixels; expose corrupt/unsupported/missing/budget failures. Preserve source bytes, orientation/profile metadata and unresolved fields. Measure concrete orientation/alpha/row-order/profile behavior on controlled PNG/BMP/JPEG fixtures and real imported assets where available. Decoder acceptance does not establish original LEADTOOLS15 format/conversion parity.
3. Test actual decoded pixels and owned buffers. Analytical raster fixtures test codecs only; never substitute a cached image for regenerated CAD geometry. Apply A01 grayscale only at the source-defined stage and channel/storage order. Do not run it on premultiplied alpha bytes as if they were BGR triples.
4. Add actual Metal texture upload, retain/dispose through in-flight frame completion, resize and replacement failure handling. Keep source CAD meshes and image planes/background separate. Source HALFTONE resampling remains a differential requirement; do not assert CoreGraphics/Metal filtering equals GDI without evidence.
5. Integrate source trace/wallpaper setters: destroy old runtime image before visible replacement; visible load failure precedes stored metadata/notifications; hidden skips decode/resize; empty clears. Do not simplify failed runtime replacement into atomic success or drop old stored metadata. Preserve notifications only through concrete parent/document adapters.
6. Verify missing/corrupt/unsupported/oversize/hidden/gray/resize/replacement/disposal cases on Windows portable boundaries and macOS/iPad/iPhone actual Apple decode/render paths. Keep strict existing screenshot gates. Physical-device/original-PC fixtures and complete source format coverage remain separate.

Record source input hashes, RED first, precise scope and real output artifacts. Use scripts/run-local.cjs for local tools and caches, all D-only; use connected owner GitHub plugin to publish and inspect Actions. No parity row closes from a decoder smoke test.

Ownership clarification from original SetDib: it creates destination storage and copies bits; false retains caller ownership of input, rather than aliasing that pointer into the result. True frees input only after successful destination creation. Decoder failure path separately frees its temporary copy. Preserve these distinctions in the concrete Apple ownership adapter.
