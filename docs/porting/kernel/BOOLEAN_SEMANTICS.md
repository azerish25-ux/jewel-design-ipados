# Boolean-node source semantics

[Body-audited contracts](boolean-caller-contracts.json) cover three registered nodes and cleanup, not all 315 lexical call families. Difference can flip to intersection and uses .01; intersection uses .01; union uses the application tolerance (startup .001). Cleanup can split kinky faces, flip inward solids and shrink faces. Channel cardinality and duplicated-input fallback are part of node behavior.

The recovered intersection body dereferences array.Length before its null check. This is a static observation, not proof that the released PC binary has the same defect. Null/empty/disjoint, ownership, order and topology cleanup cases require the contained original runtime. Do not silently fix or emulate the suspected defect without evidence.

An analytic empty OCCT result cannot be returned directly as final node output, and fuzzy tolerance is not automatically Rhino tolerance. The candidate probe implements neither caller policy nor native archive conversion.
