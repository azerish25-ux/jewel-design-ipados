# ADR0042: recovered cap construction after explicit plane selection

Status: local source/native placement checks pass; Apple cap-placement execution pending. BLD-0020/SER-0055 remain unverified. Automatic plane selection and actual graph138/139 are not implemented by this API.

The recovered CSProfileCap.Update normalizes a copied NurbsCurve with ChangeBasis(worldXY,plane), translates the fast bounding-box XY midpoint to zero without shifting Z, builds RailRevolve(CreateDomeRC(height),rail,0,zAdjust:true), places the surface with inverse(translation*basis), and stores that inverse as metadata with applyTransform:false. Geometry is already placed; applying metadata again would be incorrect.

ProfileCapWithPlaneCandidate.Build implements that construction after a caller supplies an orthonormal selected plane. It obtains the actual copied native control list through A22. The fast NURBS midpoint comes from Euclidean pole minima/maxima, consistent with the acquired SDK5 false-bounds wrapper and pinned published ON_NurbsCurve::GetBBox control-list rule. This intentionally differs from accurate curve extrema. Both transforms execute sequentially on native copies before tensor construction; the combined inverse uses double-precision affine inversion. The returned disposable result owns the already placed native face plus inverse metadata. Native intermediate curves/faces are scoped and failed creation leaves no entries.

Eighteen native face cases cover circle/asymmetric rational rails, three translated/tilted frames and negative/flat/positive domes.594 native outer-boundary points match the original rails; independently computed control-hull centers/apices and inverse translation columns match. Invalid/parallel plane axes, nonfinite height, invalid face tolerance, foreign context and BRep input are rejected with ownership cleanup. Source method hashes and inverse-order/provenance tamper controls are separate from runtime geometry checks.

[SDK/source findings](../evidence/audit/rhino5-plane-placement.json) establish the default TryGetPlane tolerance1e-12 and ChangeBasis rotation:false call. The pinned published6 NURBS plane selection uses control-triangle orientation and initial tangent alignment. This is comparison evidence rather than private Rhino5 execution. Do not replace it with a generic fitted plane and claim parity. Recovered AveragePlaneOfCurve fallback retains normalized length samples and its dot-product guard.
