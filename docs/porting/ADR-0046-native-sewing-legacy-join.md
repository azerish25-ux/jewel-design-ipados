# ADR0046: native BRep sewing and correct legacy join overload

Status: local native/shared/source tests pass; new Apple sewing execution pending. This is a kernel candidate prerequisite, not completed node140 or original-PC equivalence.

Source tracing corrected the planned join policy: CSBlocks.Solids.Obsolete.CSJoinBrep1 collects OnBrep values and calls CSUtilRhino.JoinAllBreps(OnBrep[],.01). That legacy overload calls RhUtil.RhinoJoinBreps, propagates null and invokes repair on an invalid nonnull result. The modern IEnumerable<Brep> validity/solid filter and array.Length==1 rule belong to a different overload. They must not be substituted for node140. The block only overwrites OutJoined for a nonnull result and still calls base.Update on null. [Canonical contracts](../evidence/audit/legacy-join-source-contracts.json) are hash checked in CI.

[Acquired SDK5 static inspection](../evidence/audit/legacy-join-overload.json) shows every supplied native OnBrep pointer forwarded to the single-pointer native call; nonnull output gets an owning wrapper. No original native code was executed. [Current McNeel C++9 reference](https://developer.rhino3d.com/api/cpp/group___rhino.html) documents input modification for that pointer-returning overload. This supports the ownership investigation but does not prove private Rhino5 disconnected/empty/single/repair behavior.

CandidateContext.SewBreps now performs genuine pinned OCCT sewing over deep geometry copies. Counted ABI1 inputs are bounded65536; output/56-byte topology diagnostics are zeroed on failure. Inputs need faces and cannot contain orphan non-face components that sewing would silently discard. The native result is validated before ownership transfer. Diagnostics expose actual result parts/faces/free/multiple/contiguous/deleted faces/closed shells and requested/native/min/max tolerances. Disconnected native results remain disconnected and explicitly report multiple parts. There is no modern source prefilter, forced closure, solidization or Rhino-equivalent repair in this raw operation.

Ten local cases cover adjacent and disconnected faces, tolerance gaps, an independently oriented six-face2x3x4 closed shell (volume24), a solid input, actual134/138/139 before/after radius/thickness edits and both saved/reopened generations. The actual design produces one valid three-face closed shell with zero free edges in all four states. Input geometry/tolerance bounds remain unchanged; failed/foreign/disposed/non-BRep calls retain no native entries. Eight native ABI guards reject null/count/tolerance/output/diagnostic/stale/curve cases. Native diagnostics do not establish original Rhino topology or full software parity.
