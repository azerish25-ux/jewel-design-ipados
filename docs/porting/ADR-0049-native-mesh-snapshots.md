# ADR0049: detached native BRep tessellation for viewport work

Status: local native/shared checks pass; new Apple mesh extraction pending. This supplies real geometry buffers, not a finished viewport or original-render parity.

CandidateContext.TessellateBrep meshes a deep geometry copy with explicit absolute chord and radian angle parameters. Existing triangulations are not copied, so installer/project previews cannot supply this geometry. Serial native meshing is repeated for count/fill passes; dimensions/status are checked before managed output is accepted. Short native buffers receive required counts and no partial writes. Empty native BReps return genuinely empty mesh arrays; curves are not silently converted to BRep mesh data.

Snapshots own immutable detached world-position/unit-normal arrays and zero-based triangles with mesh-local face ordinals. Vertices remain face-local to preserve normal discontinuities; face ordinals are not original project/Windows face identities. Actual surface/UV normal evaluation and native singular-node handling are used, then face location/orientation controls world normals and triangle winding. There is no manufactured geometry or coarse fallback. [Pinned source observations](../evidence/audit/native-mesh-source.json).

Nine local cases cover independent box volume/winding/all-face coverage, mirrored winding, data surviving producer-context disposal, rational-cylinder surface/radial normals, an empty Boolean BRep, and actual joined140 coarse/fine meshes, radius edit and save/reopen. The actual design produced2196 coarse triangles and108118 fine triangles under the recorded settings; finer tessellation reflects real mesher work. Original geometry/tolerance bounds and native entry counts remain unchanged. Six raw ABI cases check short vertex/index arrays with sentinel no-write controls, invalid parameters, missing counts and non-BRep input. Runtime layouts48/16/24 are checked in native/managed code.

The API currently regenerates twice per extraction and bounds exported arrays; large-model performance/cancellation, texture/UV mapping/materials, persistent face picking identity, GPU upload/viewport interaction, original Rhino tessellation/render quality, physical-device and full feature acceptance remain open.
