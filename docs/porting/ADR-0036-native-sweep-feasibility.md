# ADR0036: measured native two-rail sweep feasibility

Status: bounded Windows analytical experiment; Apple results pending. No production sweep ABI or original134 registration.

Use the pinned lower-level BRepFill_PipeShell in TKBool for the experiment. It implements the auxiliary-spine operation behind MakePipeShell without adding TKOffset/TKFillet. CMake and occt-pin.json now include TKBool; the same existing static archive merge will carry its dependency closure into Apple builds. Source hashes and exact measurements are in [A19-A02 evidence](evidence/P05-T02-A19-A02.json).

The experiment builds genuine native shells from three rectangular sections at x0/3/10, primary rail domain2..12 and secondary40..60. Tangent-plane NoContact mode retains all sections and passes native topology checks and174 independent rail/section point distances per built case. Constant width4/height1 produces four faces, no solid caps and area100. Heights1/2/1 preserve all supplied sections. Divergent straight rails with width4→6 and unit-height sections produce area110+sqrt(104)=120.1980390271856. Measured maximum residuals are below1.8e-15; acceptance remains1e-6. Equal-domain control also passes. These cases are natural straight-rail correspondence, not arbitrary paired parameter support or proof of Rhino same-height semantics.

Two rejected assumptions are now measured. Arc-length guide correspondence produces a valid-looking four-face BRep but misses the constant-section case by0.0015191738065429255 and changes area to about99.9887. Independent native untrimmed-surface projection confirms the offending sample [3,3.6,1] deviates; equal native domains give the same failure. No tolerance was relaxed. The final report explicitly labels its contact result rejected when it exceeds1e-6; the failed geometry is not accepted by the strict tangent-plane controls.

This rules out direct use for original134's three profiles. The experiment asserts this pinned behavior so a change forces review.

The candidate test report distinguishes native-sweep-feasibility=observed, tangent-plane-three-section-shell=pass, arc-length-guide-contact and contact-on-border-retained-profiles=1/3, and explicitly reports arbitrary-two-rail-correspondence=unverified. Simulator gating requires those distinct markers. A green experiment means these observations and positive analytical controls executed; it does not approve the rejected mode or register a two-rail builder.
